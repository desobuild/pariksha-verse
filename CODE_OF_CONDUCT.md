# Code of Conduct

## Our Commitment

ParikshaVerse aims to be a welcoming and constructive project for everyone who contributes to or uses the project.

We expect participants to communicate respectfully and focus on improving the project.

## Expected Behavior

Examples of constructive behavior include:

- Being respectful and considerate of others.
- Giving and receiving constructive feedback.
- Discussing technical disagreements professionally.
- Focusing criticism on ideas, code, designs, and decisions rather than individuals.
- Respecting different backgrounds, experiences, and perspectives.
- Helping keep discussions focused and useful.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Threats or intimidation.
- Deliberate disruption of discussions or project work.
- Publishing private or sensitive information without permission.
- Trolling or intentionally hostile behavior.
- Sexualized comments or unwanted advances.
- Any other conduct that would reasonably make participation unsafe or hostile.

## Project Discussions

Technical disagreement is expected and can be valuable.

When disagreements occur, participants should:

1. Explain the reasoning behind their position.
2. Refer to concrete evidence where possible.
3. Consider alternative approaches.
4. Keep the discussion focused on the project rather than individuals.

Maintainers may close or redirect discussions that become unproductive.

## Reporting Problems

For security vulnerabilities, do **not** use public GitHub issues.

See [`SECURITY.md`](SECURITY.md) for security reporting instructions.

For other conduct-related concerns, contact the project maintainer through the contact information available in the repository.

Reports will be handled as reasonably and confidentially as possible.

## Maintainer Responsibilities

Project maintainers may moderate discussions, close issues or pull requests, or restrict participation when necessary to maintain a constructive project environment.

Moderation decisions should be based on the behavior and content of the interaction rather than personal characteristics or viewpoints.

## Scope

This Code of Conduct applies to project spaces and interactions associated with ParikshaVerse, including:

- GitHub issues
- Pull requests
- Discussions
- Project documentation
- Other project-maintained communication channels

## Attribution

This Code of Conduct is intentionally concise and tailored to the ParikshaVerse project. It is informed by common open-source community standards.
